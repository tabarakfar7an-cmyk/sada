# صدى — خريطة صوتية حيّة للمدينة

موقع ثابت (HTML + CSS + JS) بدون أي أدوات بناء. جاهز للنشر على GitHub Pages.

## النشر على GitHub Pages

1. أنشئي مستودع جديد على GitHub (مثلاً `sada`).
2. ارفعي الملفات الأربعة: `index.html` و`style.css` و`app.js` و`README.md` إلى جذر المستودع.
3. من **Settings → Pages**: اختاري **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` واضغطي Save.
4. بعد دقيقة أو اثنتين بيصير الموقع على `https://USERNAME.github.io/sada/`.

## استبدال الأصوات التجريبية بتسجيلات حقيقية

الأصوات الحالية مولَّدة بالكود (Web Audio) كنسخ تجريبية. لاستخدام تسجيل حقيقي:

1. ضعي الملف (mp3 أو ogg، ٣٠ ثانية) في مجلد `audio/` بالمستودع.
2. في `app.js` أضيفي مساره كعنصر رابع بأي صوت:

```js
fajr: ['adhan', 'أذان الفجر من شرفة', 'ليلى', 'audio/weibdeh-fajr.mp3'],
```

لإضافة حيّ جديد انسخي أي عنصر داخل `PLACES` وغيّري الاسم والإحداثيات.
